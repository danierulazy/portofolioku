# Ahmad Danil — Creative Portfolio

Website portofolio pribadi Ahmad Danil, siswa SMKN 1 WAJO jurusan Desain Komunikasi Visual.

## Preview
Setelah GitHub Pages diaktifkan:
https://danierulazy.github.io/portofolioku/

## Files
- `index.html` — struktur halaman
- `style.css` — tampilan responsif dan lima tema
- `script.js` — navigasi, pencarian, filter karya, tema, dan pemutar audio

## Deploy dengan GitHub Pages
1. Buka **Settings** repository.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu Save.

## Asset note
Untuk menjaga repository portofolio lama tetap tidak tersentuh, foto, thumbnail, cover, ikon, dan file audio yang sudah ada dimuat dari repository `danierulazy/portofolio` menggunakan URL raw read-only. File di repository lama tidak diubah oleh project ini.

## Customize
Ubah teks dan tautan di `index.html`; warna dan layout di `style.css`; interaksi di `script.js`.
